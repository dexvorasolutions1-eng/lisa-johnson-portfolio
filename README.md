# Lisa Johnson — Anime Style Illustrator Portfolio

A premium, static portfolio site built with plain HTML, CSS and vanilla
JavaScript only — no React, Vite, Next.js or npm required.

## Run it
1. Open this folder in VS Code.
2. Install the "Live Server" extension (if you don't have it).
3. Right-click `index.html` → **Open with Live Server**.

## Structure
- `index.html` — page markup
- `style.css` — all styling (colors, layout, animations, responsive rules)
- `script.js` — gallery generation + nav/scroll/reveal behavior
- `images/` — put your real images here

## Placeholders you need to fill in
- **Hero banner image** — `index.html`, look for `USER WILL ADD BANNER/BACKGROUND IMAGE HERE`
  (element `.hero-banner-bg`, top of the page). In `style.css`, set
  `background-image: url('images/your-banner.jpg');` on `.hero-banner-bg`.
  You can design text (like "Commission Open") directly into that banner image
  if you want, the way a lot of commission banners do.
- **Hero circular profile photo** — `.hero-avatar`, overlaps the bottom edge
  of the banner (Facebook/WhatsApp style), with a small green "online" dot.
- **About background panel + circular photo** — look for
  `USER WILL ADD BACKGROUND IMAGE AND SMALL CIRCLE PROFILE PICTURE HERE`
  (`.about-portrait-bg` and `.about-avatar`).
- **Gallery images/videos** — every card is generated by `GALLERY_CONFIG` in
  `script.js` and marked `USER WILL ADD IMAGES`:
  - Comics: 40
  - 2D Arts: 30
  - Emotes: 20
  - Tattoos: 15
  - Videos: 3
- **Social links** — in the Contact section and footer, replace the `href="#"`
  on each Instagram / Facebook / X / TikTok / Discord icon with your real
  profile links (look for `USER WILL ADD SOCIAL LINK HERE`).
